# AI PPT Studio · 后端特性清单

> 配套文档：[`backend-design.md`](./backend-design.md)
> 版本：v1.0 · 2026-11-01
> 范围：Bun + TypeScript 后端服务的完整功能分解，共 **16 个特性域 / 187 项特性**

---

## 图例与优先级定义

| 优先级 | 含义 | 判定标准 |
|---|---|---|
| **P0** | 阻塞 | 缺此项主流程跑不通，无法上线 |
| **P1** | 核心 | 产品的差异化能力，缺此项产品无价值 |
| **P2** | 增强 | 显著提升可用性/运营效率，但不阻塞主流程 |
| **P3** | 远期 | 规模化或高级场景，后续迭代 |

| 阶段 | 对应方案路线图 |
|---|---|
| **S0** | P0 抽取 core 包（纯重构） |
| **S1** | P1 骨架 + 认证 + 持久化 |
| **S2** | P2 AI Agent 层 + 内容槽位 |
| **S3** | P3 服务端渲染与导出 |
| **S4** | P4 协作与版本历史 |
| **S5** | P5 模板提取 + 评估体系 |

**标注 ★ 的为关键特性** —— 缺此项则对应能力存在结构性缺陷（详见设计文档 §1.2）。

## A. 运行时与基础设施（INF）

| 编号 | 特性 | 优先级 | 阶段 | 说明与验收要点 |
|---|---|---|---|---|

| INF-04 | 统一错误处理中间件 | P0 | S1 | 捕获所有异常 → 统一 `{ error: { code, message, details }, traceId }`；内部错误不泄露堆栈 |

| INF-06 | 健康检查探针 | P0 | S1 | `/healthz` 存活；`/readyz` 含 DB 连通性与 Worker 队列可用性 |
| INF-07 | 优雅停机与连接排空 | P0 | S1 | 停机前停止接新任务，等在途 SSE 结束（超时 30s 强制断） |
| INF-08 | 特性开关 | P2 | S4 | 特性按用户/环境灰度，如新导出格式、实验性 Agent 版本 |
